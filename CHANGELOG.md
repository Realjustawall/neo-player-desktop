# Changelog

## 0.3.1

- Kept the Windows installer lightweight by moving Faster Whisper into an optional NEO Lyrics AI extension.
- Added consent-based first-use downloads, verified SHA-256 installation, progress, cancellation, and removal.
- Added downloadable Tiny, Base, Small, and Medium multilingual models that remain cached for offline use.
- Published the AI engine as a separate release asset; normal playback never requires it.

## 0.3.0 - Windows foundation

- expanded Spotify-inspired local library and player interface
- added Persian/English RTL, theme modes, custom colors and installed Windows fonts
- added full-drive scan, source folders and excluded-folder management
- added hidden-song recovery, collection pins and advanced playlist controls
- added normalized Persian/English search and persistent recent searches
- added playback resume, local queue, Media Session, crossfade and visualizers
- added Track+ artwork, wallpaper and Canvas profiles
- added local multilingual Whisper transcription and synchronized LRC generation
- added Windows PyInstaller, portable ZIP, NSIS installer and automated GitHub Releases
